# Supplier Pre-Read section map

Use this as the fixed skeleton every month. Source of truth for tone/structure: the Payless Pre-Read Google Doc and the uploaded `Payless Pre-Read` PDF.

Living Google Doc: https://docs.google.com/document/d/11VbsFgVPNox_8o5b-_EJ0z3QFTYIMgSkdrzn3_yf0X4

Monthly Supplier Report dashboard: https://partners.wayfair.com/d/hxVugArzfrkD6YuI94A2dq/monthly-supplier-report

## Always include (from Monthly Supplier Report PDF)

| Section | Fields to pull | Screenshot to crop |
|---|---|---|
| Greeting / agenda | Supplier team name, LCM month | — |
| Business Review header | `Business Review {Month YYYY}` | KPI cards + L12M Performance + WSC Change vs Index |
| WSC headline | LCM WSC ($K), MoM %, YoY % | performance dashboard block |
| Traffic | SKU Visit Count, MoM %, YoY % | Traffic / SKU Visit Count chart |
| CVR | LCM SKU Conversion Rate | SKU Conversion Rate chart |
| Advertising | Ad spend / LCM WSC %, spend $, Wholesale RoAS | Advertising Program Breakdown |
| Wayfair Professional | % of Sales from B2B, Pro MoM %, Pro YoY % | Sales Breakdown / B2C-B2B Growth |
| Availability | Availability (2.0) Global for LCM + short trend note | Availability - Global chart or L3M ops table |
| Dropship | Supplier Fill Rate DS (or induction fill rate if used) | L3M Operations Metrics |
| Top class context | Class name, share, MoM, YoY | Top 10 Class Breakdown |

## Usually need a second source (not in Monthly Supplier Report)

| Section | What is needed | Typical source |
|---|---|---|
| Over / under indexing vs class | WSC MoM, WSC YoY, Traffic MoM, Traffic YoY, CVR vs primary class (Payless = **Blinds & Shades**) | Prefer full-month class MoM/YoY from Traffic Hub / class scorecard. Fallback: [Window US Category Data Deep Dive](https://docs.google.com/document/d/1y_mAVBS_8qKPvZpeUg0PixR43XqF9mtarrY5PyvlTsc) monthly Blinds & Shades training table + YTD class deltas |
| Branded Competitiveness | % Uncompetitive + stacked competitiveness chart | Branded competitiveness / pricing dashboard |
| Cost Stack / pricing deep dive | Link + 1-sentence Key Point | Existing Cost Stack spreadsheet / prior-month talking point |
| Promotions / Key Asks | Upcoming events + asks | Calendar + relationship context |
| Assortment / Unfindables | Active SKU notes, specific SKUs | Catalog / tickets / prior notes |

## Voice rules (match existing Pre-Reads)

- Open with: `Hi {Team},` then one warm line about meeting / future plans.
- Agenda bullet: “I included your {Month} performance below…”
- Bold/underline the `Business Review {Month YYYY}` line.
- Use `●` / `○` / `■` nesting like the Payless PDF.
- Keep WSC as `$X.XK in WSC (+/-Y% MoM, +/-Z% YoY)`.
- End with the open invite for their talking points + `Ben`.
- Prefer short observational notes under Availability / Dropship; put relationship asks under Advertising / Competitiveness / Promotions.
