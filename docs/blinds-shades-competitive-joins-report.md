# Competitive Report: Blinds & Shades PDP Joins

## Objective

Wayfair is evaluating which joins to include for the Blinds & Shades class. Today, Wayfair primarily joins on **size** and **color**. This report reviews public competitor PDPs, category pages, and configurator flows to understand what other retailers and custom-window-treatment sellers allow shoppers to choose on PDPs.

For this report, "joins" means shopper-selectable PDP or configurator options, such as size, color, light filtration, mount style, lift/control type, liner type, or other product options.

## Executive Summary

Competitors consistently expose more than size and color for blinds and shades. Across mass retailers, home improvement retailers, direct-to-consumer blinds specialists, and premium custom sellers, the most common PDP/configurator choices are:

1. **Size / measurements**
2. **Color / fabric / finish**
3. **Light filtration / opacity**
4. **Mount type / installation type**
5. **Lift / control type**
6. **Product-specific construction choices**
   - Cell size for cellular shades
   - Liner type for Roman and woven shades
   - Roll type for roller shades
   - Valance, headrail, cassette, or fascia for custom products
7. **Motorization / smart-home compatibility**
8. **Top-down/bottom-up operation**
9. **No-drill or renter-friendly installation**

The biggest gap for Wayfair is that **light filtration, mount type, and lift/control type are treated by competitors as purchase-driving choices, not just descriptive specs**. These options map directly to customer intent:

- Do I want privacy or natural light?
- Is this for a bedroom, nursery, kitchen, media room, or living room?
- Will it fit inside my window frame?
- Do I need cordless operation for children or pets?
- Do I want top-down/bottom-up privacy control?
- Do I need motorized shades for hard-to-reach windows?

## Primary Recommendation

Wayfair should expand the Blinds & Shades join model from:

> Size + Color

to a baseline model of:

> Size + Color + Light Filtration + Mount Type + Lift / Control Type

Then Wayfair should layer in additional joins by product subtype.

## Suggested PDP Experience

For most blinds and shades, the recommended PDP option order is:

1. **Color / Fabric**
2. **Light Filtration**
3. **Mount Type**
4. **Size / Measurements**
5. **Lift / Control Type**
6. **Subtype-specific options**
7. **Hardware / finishing upgrades**

This order reflects how customers tend to shop:

1. Choose the look.
2. Choose the light/privacy function.
3. Confirm how it will install.
4. Confirm size.
5. Choose operation.
6. Add optional upgrades.

## Measurement and Fit Recommendations

Expanded joins should be paired with stronger measurement logic.

### For Inside Mount

Show:

- Minimum depth required
- Whether the factory takes deductions
- Actual received width
- Fabric width vs headrail width
- Expected side light gap

### For Outside Mount

Show:

- Recommended extra width
- Recommended extra height
- Whether ordered size equals finished size
- Best use cases: better privacy, better light blocking, shallow frames

### For No-Drill

Show:

- Whether it is inside mount only
- Tension range
- Minimum frame depth
- Surface compatibility
- Weight/size limits

## Risks and Considerations

### Risk 1: Attribute Inconsistency Across Suppliers

Many marketplace products describe light filtration, mount type, and lift type inconsistently.

**Mitigation:** Create a controlled attribute taxonomy and map supplier values into standard customer-facing values.

### Risk 2: Too Many Joins Could Overwhelm Customers

Specialist configurators can be complex. Wayfair should not expose every advanced option on every PDP.

**Mitigation:** Use progressive disclosure:

- Always show core joins.
- Show subtype-specific joins only where relevant.
- Hide advanced hardware choices under "Customize hardware" or "More options."

### Risk 3: Some Options Are Specs, Not True Variants

For example, a product may be cordless only. In that case, "cordless" should be a badge/spec, not a selector.

**Mitigation:** Use joins only when there are meaningful selectable variants. Otherwise use badges, filters, and product highlights.

### Risk 4: Fit-Related Joins Affect Returns

Mount type and size logic can create return risk if displayed without strong guidance.

**Mitigation:** Tie mount selection to measurement instructions and validation.

## Final Recommended Strategy

### Short Term

Add three new core joins:

1. **Light Filtration**
2. **Mount Type**
3. **Lift / Control Type**

This moves Wayfair from:

> Size + Color

to:

> Size + Color + Light Filtration + Mount Type + Lift / Control Type

### Medium Term

Add product-type-specific joins:

- Cellular: cell size, top-down/bottom-up, cell construction
- Roller: roll type, cassette/headrail, solar openness
- Roman: liner type, shade style
- Woven wood: liner/privacy
- Wood/faux wood blinds: slat size, tilt type
- Vertical/panel: stack direction, draw type

### Long Term

Develop a richer custom window-treatment configurator for high-AOV products, including:

- Motorization
- Smart-home compatibility
- Valance/cassette/fascia
- Hardware color
- Chain color
- Control side
- Bracket type
- Light guards
- Samples/swatches

## Bottom Line

Wayfair's current size + color join structure underrepresents how customers shop Blinds & Shades and how competitors merchandise the category.

The competitive norm is not merely visual variation. It is a combination of:

- Fit
- Light control
- Privacy
- Safety
- Operation
- Installation
- Customization

The most actionable move is to make **Light Filtration**, **Mount Type**, and **Lift / Control Type** first-class PDP joins. These are common across competitors, meaningful to customers, and directly tied to conversion, confidence, and reduced fit-related friction.
