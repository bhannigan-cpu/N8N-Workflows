# Competitive Report: Blinds & Shades PDP Joins

## Objective

Wayfair is evaluating what joins to include for the Blinds & Shades class. Today, Wayfair primarily joins on **size** and **color**. This report summarizes public competitor patterns across major blinds and shades retailers and recommends which additional PDP-selectable options Wayfair should consider.

For this report, **joins** means options that a shopper can choose from on a PDP or configurator, such as size, color, light filtering, mount style, lift type, liner, valance, or motorization.

## Executive Takeaways

Wayfair's current **size + color** join strategy is materially narrower than the competitive norm for blinds and shades. Competitors commonly expose these as PDP-selectable joins or configurator choices:

1. **Size / measurements** - universal.
2. **Color / fabric / finish** - universal.
3. **Light filtration / opacity** - very common and commercially important.
4. **Mount type / installation type** - common, especially custom and specialist sellers.
5. **Lift / control type** - common, especially cordless, continuous loop, motorized, and top-down/bottom-up.
6. **Shade construction / subtype** - common for cellular, Roman, roller, and woven wood products.
7. **Top treatment / headrail / valance / cassette** - common in specialist/custom sellers.
8. **Roll type / control side / hardware color / chain color** - advanced custom options.

## Attribute Frequency and Importance

| Attribute | Competitive Prevalence | Recommendation for Wayfair |
|---|---:|---|
| **Size / width / length** | Universal | Keep as core join. Improve measurement guidance if needed. |
| **Color / finish / fabric** | Universal | Keep as core join. Consider swatches/samples if not already surfaced. |
| **Light filtration / opacity** | Very high | Add as a primary join. This is the biggest gap after size/color. |
| **Mount type** | High | Add as a primary join where operationally supported. |
| **Lift / control type** | High | Add as a primary join, especially cordless, top-down/bottom-up, and motorized. |
| **Cordless / child-safe** | High | Could be join or badge/filter; for PDP purchase choice, treat as lift/control. |
| **Top-down/bottom-up** | High for cellular | Add under lift/control or operation type. |
| **Motorization / smart control** | High in custom/specialist retail | Add as lift/control value; badge separately for discovery. |
| **Cell size / single vs double cell** | Medium-high for cellular | Add for cellular shades where variants exist. |
| **Blackout liner / privacy liner** | High for Roman/woven/custom shades | Add for Roman/woven fabric shades. |
| **Valance / cassette / headrail** | Medium-high in custom/specialist | Add as secondary/custom join, not first-wave universal. |
| **Roll type** | Medium for roller shades | Add for custom roller shades only. |
| **No-drill / installation method** | Medium, growing | Add where true variant exists; otherwise badge/filter. |
| **Control side / chain color / bracket color** | Specialist only | Lower priority; useful for premium/custom assortment. |

## Actionable Recommendations for Wayfair

### 1. Expand From 2 Joins to a Tiered Join Model

Current:

- Size
- Color

Recommended core joins for Blinds & Shades:

1. **Size**
2. **Color / Finish**
3. **Light Filtration**
   - Sheer
   - Semi-sheer
   - Light filtering
   - Room darkening
   - Blackout
   - Solar / openness %, where applicable
4. **Mounting Location**
   - Inside mount
   - Outside mount
   - Ceiling mount, where applicable
   - No-drill / tension mount, where applicable
5. **Lift / Control Type**
   - Cordless
   - Continuous loop
   - Wand
   - Chain
   - Motorized
   - Smart/app/remote
   - Top-down/bottom-up

### 2. Use Product-Type-Specific Joins

Do not force every join onto every blinds/shades PDP. Use conditional joins by product subtype:

| Product Subtype | Recommended Additional Joins |
|---|---|
| **Cellular / honeycomb shades** | Light filtration, cell size, single vs double cell, top-down/bottom-up, cordless/motorized |
| **Roller shades** | Light filtration, roll type, headrail/cassette/fascia, lift/control, solar openness |
| **Roman shades** | Liner type, shade style/fold style, cordless/control type, mount |
| **Woven wood / bamboo shades** | Privacy/blackout liner, color/material tone, cordless/control, mount |
| **Faux wood / wood blinds** | Slat size, tilt type, lift/control, mount, valance |
| **Vertical blinds / panel tracks** | Stack/draw direction, wand/cord control, panel count/track, mount |

### 3. Prioritize "Light Filtration" as the First New Join

This appears across almost every competitor and directly maps to shopper intent: privacy, sleep, glare reduction, nurseries, media rooms, living rooms, and offices.

It is more than a spec; it is a purchase-driving choice. Wayfair should expose it as a selectable PDP option where variants share the same base product.

### 4. Add "Lift / Control Type" as the Second New Join

Competitors repeatedly emphasize cordless, top-down/bottom-up, and motorized as differentiators. This join also supports safety messaging.

Recommended taxonomy:

- Cordless
- Corded
- Continuous loop
- Wand control
- Chain control
- Motorized
- Smart motorized
- Top-down/bottom-up cordless
- Top-down/bottom-up motorized

### 5. Add "Mount Type" Where Fulfillment and Spec Logic Support It

Inside vs outside mount materially changes measurement guidance, deductions, fit, light gaps, and customer satisfaction. Specialist competitors often ask for mount type before size or alongside size.

If Wayfair cannot support true made-to-measure deductions universally, it should at least:

- Expose mount type on eligible SKUs.
- Show measurement rules dynamically.
- Prevent customers from picking incompatible size/mount combinations.

### 6. Keep Advanced Joins for Custom/Premium Products

For premium/custom blind PDPs, Wayfair should consider:

- Headrail / cassette / valance
- Roll direction
- Liner type
- Cell size
- Control side
- Hardware color
- Chain color
- Light guards
- Smart bridge/accessory compatibility

These are not necessary for every commodity blind, but they are common on specialist sites and can support higher average order value.

## Recommended Wayfair Roadmap

### Phase 1: High-Impact Core Expansion

- Add **Light Filtration**.
- Add **Lift / Control Type**.
- Add **Mount Type** for eligible products.

### Phase 2: Subtype-Specific Enrichment

- Cellular: cell size, top-down/bottom-up, single/double cell.
- Roller: roll type, cassette/headrail, solar openness.
- Roman/woven: liner type, shade style.

### Phase 3: Premium Custom Configurator

- Bracket/hardware color.
- Chain color.
- Control side.
- Valance/cornice upgrades.
- Smart-home accessories.

## Bottom Line

Wayfair should not stop at size and color. The competitive standard for blinds and shades is:

> Size + Color + Light Filtration + Mount Type + Lift / Control Type

Those five should become the baseline join strategy, with additional joins layered by shade subtype and customization depth.
