# Smart Bedding — by-module report

Soft Home · Bedding · Winter / Fall 2026  
Owners: Clark Lewis / Allie Jeffay (PM); Jaiden Lawlor / Ben Hannigan (CM); Missy Paragamian direction

**Bottom line:** Discovery and seasonality are the leak. Cooling still holds promo real estate in winter while heated/cozy merchandising already exists on ICP. Fix nav + seasonality first; then standardize Superbrowse/search and upgrade PDP packaging.

| Metric | Value |
| --- | --- |
| Cooling top-nav L30D visits | 217 |
| Downstream CVR on that link | 14.3% |
| Supplier-reported share vs comps | &lt;10% |
| Awareness → consideration | 29% (Walmart 68%) |
| ICP Smart Bedding blocks | Under-indexed visits; ~26% ATC / ~6.5% CVR (over-indexed conversion) |

## 1. Top nav / flyout / RHR

**Verdict: Broken seasonality — P0**

### What we see
- **Cooling Bedding** still sits in Bed & Bath flyout / RHR in winter.
- Missy (Oct 20): remove out-of-season cooling; scrape Brooklinen / Parachute for the right pattern.
- Flyout refreshes are quarterly / high PM lift → seasonal swaps lag.

### Why it matters
- Low traffic (217 L30D) but **high intent** (14.3% downstream CVR) → discoverability is the leak, not demand.
- Site looks unmaintained when Cooling is the winter hero.

### Recommendation
| Action | Owner cue |
| --- | --- |
| This week: swap Cooling → **Heated Bedding** or **Winter Bedding** hub (flannel, fleece, wool, heated, heavier fills) | Clark / Allie |
| Keep Cooling via SB filters + search redirects — demote promo slot, don’t delete assortment | CM |
| Publish Mar/Apr and Sep/Oct swap calendar with named owner | PM |

## 2. Trending Now

**Verdict: Partial win — align with nav**

### What we see
- **Heated Blankets** earned 4th Trending Now slot — winter framing is already working here.
- Disconnect: Trending leads heated while flyout still leads Cooling.

### Recommendation
- Make Trending + flyout + ICP tell the **same seasonal story**.
- Use Trending as the always-on entry to the evergreen **Sleep Climate** hub (see §4).

**Verdict: Partial — winter storytelling exists; Smart Bedding architecture does not**

### What we see (Wayfair)
User-provided winter ICP module — **“stay warm on cool nights”**:

| Tile | Role |
| --- | --- |
| Fall for texture | Seasonal aesthetic / cozy materials |
| Heated blankets | Explicit Smart / performance warmth |
| Extra-warm duvet fills | Insulation / fill warmth |

Internal signal: ICP Smart Bedding blocks **under-index visits** but **over-index ATC (~26%) and CVR (~6.5%)** → when customers find the blocks, they convert; volume is the gap.

### Competitive bar
- Brooklinen: dedicated Cooling Shop + education LP (not a single tile in a mixed carousel).
- Specialty players treat climate as a **destination**, not one of three seasonal tiles.

### Recommendation
| Now | Next |
| --- | --- |
| Keep / amplify winter ICP (`stay warm…`) while Cooling is demoted from nav | Build recurring ICP pattern: Sleep Cooler · Sleep Warmer · Weighted · All-Season |
| Add heated / extra-warm feature callouts in grid near ICP | Link every climate tile into a single Sleep Climate hub |

## 4. Dedicated landing page / Sleep Climate hub

**Verdict: Missing as a coherent destination — P1**

### What we see
- No durable, need-based **Sleep Climate** hub comparable to Brooklinen’s Cooling Shop.
- Wayfair has fragments (filters, seasonal ICP, Trending) but not one education → shop journey.

### Competitive bar
- **Brooklinen Cooling Shop** — benefit headline + curated grids.
- **Brooklinen Our Bed’s Cooler** — fabric education carousel *before* PLP.
- **Eight Sleep** — temperature as year-round sleep tech, not a season.

### Recommendation
Ship evergreen LP:

1. Hero by need (Sleep Cooler / Sleep Warmer / Weighted / All-Season)  
2. Fabric / tech education modules  
3. Curated grids by class  
4. FAQ + proof (certs, awards)  
5. Entry points: Trending, ICP, flyout seasonal hero, search redirects

## 5. Superbrowse

**Verdict: Not enough — P1**

### What we see

**Bedding Sets SB** — Cool & Breathable exists as a filter, not a curated Smart Bedding shop:

![Wayfair Bedding Sets Superbrowse](screenshots/wf-bedding-sets-sb.jpg)

**Sheets SB** — material education started; Smart / Heated not first-class:

![Wayfair Sheets Superbrowse](screenshots/wf-sheets-sb.jpg)

### Gaps
- Climate / performance facets not standardized across classes.
- No UB-style **feature callouts** for cooling / heated / temp-regulating in-grid.
- Feels like “assortment + generic filters,” not a need shop.

### Recommendation
- Standardize facets: Cooling · Heated · Temp-regulating · Moisture-wicking · Extra warm (when unlocked).
- Add feature callouts / badges on cards (Purple pattern).
- Wire SB filters to the Sleep Climate hub and search redirects.

## 6. Search + redirects

**Verdict: Partial — P1**

### What we see
- Intent exists (cooling / heated queries; Cooling nav CVR is strong).
- Competitive SERPs (Amazon) lead with **performance nouns in titles** + social proof density.

![Amazon cooling sheets](screenshots/comp-amazon-cooling-sheets.jpg)

### Recommendation
- CM owns search-term → Sleep Climate / class SB redirects for cooling, heated, hot sleeper, weighted, etc.
- Align title/attribute taxonomy so SB filters and search share the same nouns.

## 7. Filters / facets

**Verdict: Inconsistent — P1**

### What we see
- Material / size / color dominant on SB.
- Performance climate attributes present in places (e.g. Cool & Breathable) but not a coherent Smart Bedding system.

### Recommendation
| Facet | Classes |
| --- | --- |
| Cooling / Cool & Breathable | Sheets, sets, comforters, mattress toppers |
| Heated | Blankets, mattress pads, throws |
| Extra warm / heavier fill | Comforters, duvets, quilts |
| Temp-regulating / moisture-wicking | Sheets, protectors, performance lines |
| Weighted | Blankets, comforters |

## 8. PDP

**Verdict: Not enough — P1–P2**

### What we see
- Conversion on ICP blocks is healthy when found → PDP/offer can work.
- Titles and proof lag Amazon / Boll & Branch / Purple (performance nouns, awards, in-grid feature tags).

### Competitive bar
- **Boll & Branch:** hot-sleeper copy + Cotton Cooling + awards on PLP/PDP path.  
  ![Boll & Branch](screenshots/comp-bollbranch-percale-cooling.jpg)
- **Purple:** moisture-wicking / stretch tags on cards.  
  ![Purple](screenshots/comp-purple-bedding.jpg)
- **Amazon:** “Breathable & Cooling,” “for Hot Sleepers,” Q-Max / °F claims in title.

### Recommendation
- Performance nouns in titles on curated SKUs (cooling, heated, moisture-wicking, hot sleeper).
- Waymore demos for climate claims.
- Certs / awards / third-party proof near fold (align with bedding survey top-200 quality work).
